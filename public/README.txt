Apexa AI Labs — Next.js Logo Pack

Recommended Next.js App Router setup:
- app/favicon.ico                -> favicon.ico
- app/icon.png                   -> icon-512.png (or icon-emblem-512.png)
- app/apple-icon.png             -> apple-touch-icon.png
- public/icons/icon-192.png     -> icon-192.png
- public/icons/icon-512.png     -> icon-512.png
- public/icons/maskable-512.png -> maskable-icon-512.png

For a small browser/taskbar/search favicon, use the emblem-only files:
- favicon-16x16.png
- favicon-32x32.png
- favicon-48x48.png
- favicon.ico

For larger branding, use:
- logo-256.png
- logo-512.png
- logo-1024.png

For social/Open Graph previews:
- og-image-1200x630.jpg

The emblem-only files have transparent backgrounds; the full-logo files retain the original dark background.
